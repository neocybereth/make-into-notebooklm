# v1.1.2 verification

Date: 2026-09-23. Extension version: 1.1.2.

## Defect and regression check

The live signed-in NotebookLM homepage exposes a button with
`aria-label="New notebook"`. Version 1.1.1 only matched `Create notebook` and
`Create new notebook`, so the importer waited on the homepage until its
45-second timeout. The existing fixture only used the older label.

Before changing the importer, the existing full-flow fixture was expanded to
exercise all three labels. The new label failed with `Importer did not reach
expected state`; both older labels passed. After the selector fix, all three
complete notebook creation, URL submission and exactly one `summarize` request.

Repeat the regression and repository checks:

```sh
npm ci
node --test --test-name-pattern='creates via' tests/importer.test.js
npm run check
```

Result: 20 checks passed; ESLint passed with cyclomatic complexity limited to 8.
These are Node/JSDOM integration checks with simulated Chrome messaging and
Google controls, not a live browser E2E test.

## Installed-extension E2E procedure

1. Reload version 1.1.2 at `chrome://extensions` in a signed-in Chrome profile.
2. Open a public YouTube video that NotebookLM can import.
3. Invoke **Make into NotebookLM** using the toolbar popup.
4. Confirm that the newly opened homepage advances through **New notebook**,
   **Websites**, URL entry and **Insert** without intervention.
5. Confirm one selected video in **Sources** and exactly one **summarize**
   message in chat. Wait for the reply.
6. Reload the resulting notebook and verify no duplicate source or prompt.
7. Repeat using the keyboard shortcut or context-menu entry in a new notebook.
8. Save a screenshot of Sources and the single summarize message, the private
   notebook URL, extension version and chosen video URL as local evidence.
   Do not publish account information or unrelated notebook contents.
